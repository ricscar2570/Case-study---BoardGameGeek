# BoardGameGeek Data Case Study

> **Repository status:** exploratory data-analysis case study.

This repository is a Jupyter-based analysis workspace built around BoardGameGeek-derived board-game data. It is preserved as a portfolio case study and research workspace rather than a production application.

## What is in the repository

- `BoardGameTHIS!!!.ipynb` — main exploratory-analysis notebook.
- `UpdateDB.ipynb` — notebook used for dataset update/preparation work.
- `bgg_data_documentation.txt` — notes describing the data.
- CSV snapshots for games and reduced designer, artist, mechanic and publisher data.

## Scope

The repository demonstrates notebook-based data exploration, preparation and analysis in the board-game domain. The committed CSV files are snapshots used by the analysis; they should not be interpreted as a live or complete mirror of BoardGameGeek.

## Portfolio classification

**Category:** Data Analytics / Jupyter case study  
**Maturity:** exploratory analysis workspace  
**Use:** portfolio, research history and reproducibility of the notebooks

This repository is intentionally kept separate from deployable software projects and from production systems.
